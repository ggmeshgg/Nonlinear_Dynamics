# Строгац 6.4.9 — национальная экономика

Подробное решение пунктов (a), (b), (c) упражнения 6.4.9 из *Nonlinear
Dynamics and Chaos* и интерактивная лаборатория на русском языке.

## Модель и предположения

Национальный доход `I` и потребительские расходы `C` удовлетворяют
`I' = I − αC`, `C' = β[I − C − G(I)]`, где `α > 1`, `β ≥ 1`.
Рассмотрены три заданных в упражнении правила государственных расходов:
постоянное `G = G₀`, линейное `G = G₀ + kI` и квадратичное
`G = G₀ + kI²`, с `G₀ ≥ 0`, `k > 0`.

Экономическая область — `I ≥ 0`, `C ≥ 0`; она в общем случае не инвариантна.
По умолчанию выбранная траектория останавливается на первом выходе из неё.
Продолжение на полной плоскости включается отдельно и имеет только
математический смысл. Все параметры и время выражены в условных единицах.

На странице последовательно разобраны нульклины, равновесия, якобиан,
устойчивость, критические значения параметров и фазовые портреты.
Особое внимание уделено консервативному случаю `β = 1`, затуханию при
`β > 1`, исключению `G₀ = 0` и границам экономической интерпретации.
Методы связаны с §§6.1–6.5; вводная иллюстрация кейнсианского креста
поясняет экономический контекст и не подменяет уравнения Строгаца.

## Запуск и проверка

Откройте `index.html` в браузере или используйте общий предпросмотр клуба.
Внешних библиотек, шрифтов и сетевых запросов для симуляции нет.
На GitHub Pages проект размещается под `/Nonlinear_Dynamics/strogatz-6.4.9/`.

`model.js` содержит формулы модели, классификацию равновесий и интегратор
Рунге—Кутты четвёртого порядка. `app.js` отвечает за графики и управление.
Положение равновесий рассчитывается аналитически; сепаратриса седла —
численно. Ограничения расчёта указаны в лаборатории.

Контрольный пример: `α = 2`, `β = 3`, `k = 0.1`, `G₀ = 0.4` даёт
устойчивый фокус `(1, 0.5)` и седло `(4, 2)`. При `β = 1` меньшая точка
становится нелинейным центром. Порог слияния — `G₀,c = 0.625`.

Полное решение находится на странице; отдельного PDF нет. Кнопка печати
позволяет сохранить страницу в PDF средствами браузера.
