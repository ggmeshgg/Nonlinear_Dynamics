При β = 1 модель консервативна: около центра возможны незатухающие колебания. При β > 1 появляется затухание. Но даже устойчивое равновесие не гарантирует, что произвольная траектория сохранит неотрицательные доход и потребление.

01 / ПОСТАНОВКА · §6.4

От кейнсианского креста
к двум уравнениям

Экономическая идея за минуту

В кейнсианском кресте сопоставляют выпуск, или доход Y, и планируемые совокупные расходы AE. Линия AE = Y показывает равенство расходов и выпуска. Её пересечение с графиком AE(Y) задаёт равновесие. В простой версии цены считают фиксированными: если расходы выше выпуска, незапланированные запасы сокращаются и фирмы увеличивают производство; если ниже — запасы накапливаются и выпуск сокращается.

Например, при AE(Y) = A + cY, где A — автономные расходы, а 0 < c < 1 — доля дополнительного дохода, направляемая на потребление, равновесный доход равен Y* = A/(1 − c). Расходы одних становятся доходами других — так возникает мультипликатор. В более общей записи AE = C(Y − T) + J + G + NX: потребление, инвестиции J, государственные закупки и чистый экспорт; T — налоги. Этот рисунок описывает равновесие, но ещё не задаёт единственную возможную динамику.

ИЛЛЮСТРАЦИЯ ОБЩЕЙ ИДЕИ

AE = A + 0,6Y

Условные единицы. Это отдельная иллюстрация статического креста, а не траектория системы Строгаца.

Именно модель из упражнения

İ = I − αCĊ = β[I − C − G(I)]

Параметры: α > 1, β ≥ 1.
Экономические переменные: I ≥ 0, C ≥ 0, G ≥ 0.

Точка над буквой — производная по времени. İ означает скорость изменения дохода, а не сам доход.

ОбозначениеСмыслКак читать в этой модели
I(t)Национальный доходЗдесь I — доход, а не инвестиции. В обычных макроэкономических формулах доход часто обозначают Y.
C(t)Потребительские расходыАгрегированный поток расходов, сопоставимый с доходом в выбранных единицах.
G(I)Государственные расходыВнешне заданное правило: константа, линейная или квадратичная функция дохода.
α > 1Коэффициент первого уравненияПри İ = 0 получаем C = I/α. В общем движении это не тождественная функция потребления.
β ≥ 1Относительный темп изменения CПосле исключения C коэффициент затухания равен β − 1.
G₀ ≥ 0, k > 0Базовые расходы и сила зависимости от IВ линейном и квадратичном правиле k имеет разный масштаб; численные значения нельзя напрямую сравнивать.
Для экономиста и для инженера

Строгац задаёт конкретную систему приспособления. Из кейнсианского креста нельзя автоматически вывести именно эти знаки и скорости. Например, при фиксированных I и C увеличение G уменьшает Ċ. Сохраняем уравнения условия и интерпретируем их буквально. Числа ниже — учебные, без привязки к реальной стране или периоду.

Три части задачи

  1. G = const ≥ 0: найти и классифицировать равновесие; показать колебания при β = 1.
  2. G = G₀ + kI: найти порог kc существования экономически допустимого равновесия и объяснить поведение выше него.
  3. G = G₀ + kI²: показать возможность двух, одного или нуля равновесий; интерпретировать фазовые портреты.

Условие передано своими словами и сверено с учебником. Для утверждений об исчезновении равновесия в (b) важно G₀ > 0; граничный случай G₀ = 0 разбирается отдельно.

02 / ОБЛАСТЬ И НУЛЬКЛИНЫ · §6.1–6.2

Допустимая область —
ещё не инвариантная область

Математически полиномиальные уравнения определены на всей плоскости. Экономически рассматриваем замкнутый первый квадрант

Q = {(I,C): I ≥ 0, C ≥ 0}.

Для заданных правил и G₀ ≥ 0 также G(I) ≥ 0 при I ≥ 0. Но Q не инвариантен. Проверяем направление поля на границах:

Граница I = 0

İ = −αC < 0 при C > 0.

Стрелка направлена к отрицательному доходу — наружу из Q.

Граница C = 0

Ċ = β[I − G(I)].

Если I < G(I), потребление становится отрицательным. При G₀ > 0 это происходит и в начале координат.

Теорема единственности из §6.2 не спасает экономическую область: здесь оси в общем случае не являются траекториями, поэтому пересечение оси не нарушает единственность. Решение математически продолжается, пока существует, но исходная экономическая интерпретация прекращается при первом выходе из Q.

Две нульклины для всех трёх правил

İ = 0 ⇔ C = I/α,
Ċ = 0 ⇔ C = I − G(I).
Положение точкиЗнак скоростиНаправление
Ниже C = I/αİ > 0Вправо →
Выше C = I/αİ < 0Влево ←
Ниже C = I − G(I)Ċ > 0Вверх ↑
Выше C = I − G(I)Ċ < 0Вниз ↓

На первой нульклине движение вертикально, на второй — горизонтально. Только их пересечение является равновесием. Это схема анализа §6.1; затем, как в §6.4, дополняем её устойчивостью и траекториями.

Общая формула якобиана

J = 1−αβ[1 − G′(I)]−β
τ = tr J = 1 − β,
Δ = det J = β[α − 1 − αG′(I*)],
λ² − τλ + Δ = 0,   Dλ = τ² − 4Δ.

След τ равен сумме собственных значений, определитель Δ — их произведению. Если Δ < 0, знаки различны: это седло. Если Δ > 0 и τ < 0, обе действительные части отрицательны: равновесие притягивает. Дискриминант Dλ различает узел и фокус. Эти правила идут из §5.2 и применяются через линеаризацию в §6.3.

03 / ПУНКТ (a) · G = CONST

Одна точка.
Два разных смысла устойчивости.

1

Находим равновесие

I* = αC*,   I* = C* + G
⇒ (α − 1)C* = G
⇒ C* = G/(α − 1),   I* = αG/(α − 1).

При G > 0 обе координаты положительны. При G = 0 равновесие — начало координат, которое входит в замкнутый первый квадрант.

2

Переносим начало координат

Положим u = I − I*, w = C − C*. Постоянные слагаемые сокращаются:

u̇ = u − αw,   ẇ = β(u − w),
τ = 1 − β,   Δ = β(α − 1) > 0.

Это точно линейная система, а не локальная аппроксимация. Поэтому классификация справедлива на всей математической плоскости.

УсловиеТипЧто происходит
β > 1, Dλ < 0Устойчивый фокусЗатухающие колебания вокруг равновесия.
β > 1, Dλ > 0Устойчивый узелЗатухание без колебательных собственных мод. Отдельная координата не обязана меняться монотонно.
β > 1, Dλ = 0Вырожденный устойчивый узелКратное отрицательное λ; матрица не скалярна, поэтому это не звёздный узел.
β = 1ЦентрУстойчив, но не асимптотически устойчив. Неподвижна только сама точка; соседние математические траектории замкнуты.
Dλ = (β − 1)² − 4β(α − 1).
Где точно проходит граница узел / фокус?

Решая Dλ = 0 по β, получаем β = 2α − 1 ± 2√[α(α − 1)]. Нижний корень меньше 1. Поэтому в разрешённом диапазоне

βn = 2α − 1 + 2√[α(α − 1)].

При 1 < β < βn — фокус; при β = βn — вырожденный узел; при β > βn — узел.

3

Доказываем колебания при β = 1

Дифференцируем u̇ = u − αw и подставляем ẇ = u − w:

ü = u̇ − αẇ = u̇ − αu + αw = −(α − 1)u.
ü + ω²u = 0,   ω = √(α − 1),
u(t) = A cos(ωt) + B sin(ωt),
T = 2π/√(α − 1),   w = (u − u̇)/α.

В плоскости (I,C) получаются эллипсы. Амплитуда не убывает. Здесь чисто мнимые λ действительно означают центр, поскольку после сдвига система точно линейна.

Колебания должны помещаться в Q

При G > 0 достаточно малые эллипсы вокруг положительного равновесия целиком допустимы. Большие могут пересекать оси. При G = 0 центр расположен на границе, и ни один непостоянный замкнутый эллипс вокруг него целиком не лежит в первом квадранте. Фраза «экономика будет колебаться» требует этой оговорки.

04 / ПУНКТ (b) · G = G₀ + kI

Когда равновесие
уходит на бесконечность

Пусть k > 0. Введём удобное обозначение q = 1 − 1/α > 0. Тогда

Ċ = β[(1 − k)I − C − G₀],
C = I/α,   C = (1 − k)I − G₀.

Приравниваем нульклины:

I*/α = (1 − k)I* − G₀
⇒ (q − k)I* = G₀
⇒ I* = G₀/(q − k),   C* = I*/α.

Основной случай: G₀ > 0

Значение kРавновесиеУстойчивость
0 < k < qЕдинственная положительная точкаβ > 1: устойчивый узел или фокус. β = 1: центр.
k = qТочки нет: нульклины параллельны и различныКлассифицировать равновесие нельзя — его не существует.
k > qТочка с I*,C* < 0Седло на математической плоскости, за пределами экономической области.
kc = q = 1 − 1/α,
Δ = αβ(q − k),   τ = 1 − β.

При k < kc используем тот же дискриминант Dλ = (β − 1)² − 4αβ(q − k). При β = 1 период равен T = 2π/√[α(q − k)].

При k → q снизу I* → +∞ и C* → +∞. Это не локальное слияние двух конечных точек: в положительной области пересечение удаляется на бесконечность. Во втором пункте пока нет обычной седло-узловой бифуркации.

Что происходит при k > kc?

Нельзя заключить, что вся экономика обязательно растёт бесконечно. На полной плоскости седло имеет одну растущую и одну затухающую моду. Направление растущей моды зависит от k:

λ₊ = [1 − β + √((β − 1)² + 4αβ(k − q))]/2 > 0,
δC/δI = (1 − λ₊)/α.
  • q < k < 1: λ₊ < 1, так что растущая мода допускает совместный положительный рост I и C. Есть траектории, которые остаются в Q и растут неограниченно. Другие начальные состояния могут выйти из Q.
  • k ≥ 1 и G₀ > 0: пока I,C ≥ 0, имеем Ċ = β[(1 − k)I − C − G₀] ≤ −βG₀. Поэтому любая такая траектория покинет Q не позже C₀/(βG₀), если раньше не пересечёт I = 0. Здесь интерпретация «вечный положительный рост» уже невозможна.
А что происходит ровно при k = kc?

В переменных I и v = İ получается v̇ + (β − 1)v = αβG₀. При β > 1 скорость v стремится к αβG₀/(β − 1); математически I растёт асимптотически линейно. При β = 1 имеем I(t) = I₀ + v₀t + αG₀t²/2. Но конкретный путь может раньше покинуть Q, поэтому эти формулы не отменяют проверку допустимости.

Обязательное исключение: G₀ = 0

При любом k начало координат остаётся равновесием. При k ≠ q это единственная точка, при k = q вся прямая C = I/α состоит из равновесий; в Q остаётся её неотрицательный луч. Поэтому утверждение «после порога нет ни одного равновесия в первом квадранте» требует G₀ > 0.

При k < q классификация начала та же: сток для β > 1, математический центр для β = 1. При k > q это седло. На линии k = q при β > 1 есть поперечное затухание и нейтральное направление вдоль линии; отдельные точки не асимптотически устойчивы. При β = 1 матрица ненулевая, но имеет два нулевых собственных значения: рядом с линией возникает линейный по времени дрейф, и её точки неустойчивы. Эти утверждения относятся к полной математической системе.

05 / ПУНКТ (c) · G = G₀ + kI²

Две точки встречаются.
Но какие именно?

Первая нульклина остаётся прямой C = I/α. Вторая — парабола C = I − G₀ − kI², ветвями вниз. Увеличение G₀ сдвигает параболу вниз.

1

Считаем пересечения

I*/α = I* − G₀ − k(I*)²
⇒ k(I*)² − qI* + G₀ = 0,
d = q² − 4kG₀,
I*± = [q ± √d]/(2k),   C*± = I*±/α.

Здесь d — дискриминант уравнения для равновесий. Не путать с Dλ, который классифицирует собственные значения.

G₀,c = q²/(4k) = (α − 1)²/(4kα²).
УсловиеЧисло точек в QГеометрия
0 < G₀ < G₀,cДве, обе положительныеДва пересечения прямой и параболы.
G₀ = G₀,cОднаКасание в Ic = q/(2k), Cc = Ic/α.
G₀ > G₀,cНи однойПересечений нет.
G₀ = 0Две, включая границу(0,0) и (q/k, q/(αk)).
2

Классифицируем обе точки при d > 0

G′(I) = 2kI,
Δ(I*) = αβ(q − 2kI*),
Δ₋ = +αβ√d > 0,   Δ₊ = −αβ√d < 0.

Большая точка всегда седло. Меньшая при β > 1 — асимптотически устойчивый узел или фокус; различаем их по Dλ,− = (β − 1)² − 4αβ√d. При β = 1 линейная часть даёт мнимые λ, но этого ещё недостаточно для вывода «центр». Доказательство через энергию — в следующем разделе.

ПРИМЕР ИЗ ИСХОДНОГО РАЗБОРА
α = 2, β = 3, k = 0,1, G₀ = 0,4
q = 0,5,   d = 0,09,   G₀,c = 0,625.

Меньшая точка (1; 0,5): Δ = 1,8, τ = −2, Dλ = −3,2; это устойчивый фокус. Большая (4; 2): Δ = −1,8; это седло. При G₀ = 0,625 они встречаются в (2,5; 1,25).

3

Разбираем само касание, а не только соседние случаи

При d = 0 собственные значения равны 0 и 1 − β. Нулевое значение требует нелинейного анализа. Положим u = I − Ic и v = İ. В критической точке получаем точную систему

u̇ = v,
v̇ = −(β − 1)v + αβku².

β > 1: одно направление затухает. На локальном центральном многообразии v = au² + …; подстановка даёт a = αβk/(β − 1), поэтому

u̇ = [αβk/(β − 1)]u² + O(u³).

При u < 0 движение направлено к нулю, при u > 0 — от нуля. Критическая точка притягивает с одной стороны, но не является устойчивой по Ляпунову. Это обычная седло-узловая бифуркация. Перед слиянием сток уже является узлом, даже если дальше от порога он был фокусом.

β = 1: оба λ равны нулю, и ü = αku². Линейная классификация здесь бессильна. Потенциал имеет стационарную точку перегиба, а не минимум; критическое равновесие неустойчиво. Это консервативное слияние центра и седла — не обычный седло-узел с одним нулевым λ.

Центральное многообразие и классификация бифуркаций развиваются дальше, в главе 8. Для решения главы 6 достаточно увидеть вырожденность и проверить движение через точное уравнение второго порядка.

Граничное равновесие при G₀ = 0

Меньшая точка теперь лежит в начале координат. При β = 1 это центр полной математической системы, но замкнутые орбиты вокруг него не помещаются целиком в Q. При β > 1 математическая устойчивость начала также не превращает весь первый квадрант в инвариантную область.

Фазовый портрет и бассейн притяжения

При β > 1 и d > 0 устойчивое многообразие седла образует часть границы математического бассейна стока (§6.4). Оно отделяет траектории с различным долгосрочным поведением. Это не нульклина: нульклина задаёт нулевую компоненту скорости, а сепаратриса сама является траекторией.

При β = 1 меньшая точка не притягивает окрестность: вокруг неё лежит семейство замкнутых орбит. На полной плоскости сепаратриса седла образует гомоклиническую петлю вокруг центра. Петля может частично лежать вне Q. Например, при α = 2, k = 0,1, G₀ = 0,4 её левый поворот по I равен −0,5. Поэтому даже красивый замкнутый математический контур не обязательно является допустимым экономическим циклом.

При G₀ > G₀,c равновесий нет. Из уравнения второго порядка следует отсутствие ограниченного устойчивого режима на всей плоскости; выбранные траектории могут покидать Q. Экономический вывод — отсутствие сбалансированного стационарного состояния в рамках этой модели, а не доказательство неизбежного кризиса реальной экономики.

06 / КЛЮЧЕВОЕ РАЗЛИЧИЕ · §6.3 И §6.5

β = 1: колебаться.
β > 1: терять «энергию».

Чисто мнимые собственные значения нелинейной системы ещё не доказывают центр: нелинейные члены могут превратить его в фокус (§6.3). Здесь помогает сохраняющаяся величина из §6.5.

Шаг 1. Исключаем потребление

C = (I − İ)/α,
Ï = İ − αĊ
= İ − αβ[I − (I − İ)/α − G(I)]
= −(β − 1)İ − β[(α − 1)I − αG(I)].
Ï + (β − 1)İ + V′(I) = 0,
V′(I) = β[(α − 1)I − αG(I)].

Математически это движение частицы с трением. Доход играет роль координаты; v = İ = I − αC — скорость. Замена (I,C) ↔ (I,v) обратима, но ось v не является осью потребления.

Шаг 2. Проверяем производную «энергии»

E(I,C) = ½(I − αC)² + V(I),
Ė = İ[Ï + V′(I)] = −(β − 1)İ² ≤ 0.

E — математическая функция состояния, а не деньги, ВВП, капитал или благосостояние. Слово «энергия» используется по аналогии с механикой.

Правило расходовПотенциал V(I), с точностью до константы
G = G₀β[(α − 1)I²/2 − αG₀I]
G = G₀ + kIβ[(α − 1 − αk)I²/2 − αG₀I]
G = G₀ + kI²β[(α − 1)I²/2 − αG₀I − αkI³/3]

β = 1: E сохраняется

В строгом локальном минимуме V точка (I*,v = 0) — минимум E. Близкие уровни энергии замкнуты: по теореме 6.5.1 получаем нелинейный центр.

Малая возмущённая система остаётся рядом, но не возвращается в равновесие. Нет открытого бассейна притяжения центра.

β > 1: E убывает

Энергия теряется там, где İ ≠ 0. Около строгого минимума V это приводит к затуханию и локальному притяжению.

Но убывание E не означает глобальную устойчивость: кубический потенциал квадратичной политики не ограничен снизу при I → +∞.

Почему меньшая точка в (c) — центр при β = 1?

V″(I*) = β[α − 1 − 2αkI*] = Δ(I*).
V″(I*₋) > 0,   V″(I*₊) < 0.

Меньшая точка — минимум V, большая — максимум. Первая даёт центр, вторая — седло. При β = 1 период малых колебаний около меньшей точки равен Tмал = 2π/√(α√d). Для конечной амплитуды квадратичной модели период в общем зависит от энергии: это не точная формула общего периода.

Как энергия описывает петлю и почему она не всегда экономическая?

При β = 1 граница замкнутых колебаний задаётся уровнем E = V(I*₊). Скорость v = ±√[2(E − V(I))], а C = (I − v)/α. Для кубического потенциала левый поворот гомоклинической петли равен

Iturn = (3I*₋ − I*₊)/2.

В примере I*₋ = 1, I*₊ = 4 это −0,5. Даже при I ≥ 0 нужно проверить C ≥ 0 на всей орбите. Период замкнутых орбит растёт при приближении к петле; сама петля достигает седла только при бесконечном времени и не является периодическим решением.

Почему при β > 1 нет непостоянных замкнутых орбит?
E(T) − E(0) = −(β − 1) ∫₀ᵀ İ² dt.

Если траектория вернулась в исходное состояние за период T, левая часть равна нулю. При β > 1 это требует İ ≡ 0. Тогда I постоянно, C = I/α тоже постоянно: остаётся равновесие. Затухающий фокус не является предельным циклом.

Математический бассейн ≠ допустимое экономическое возвращение

Траектория может математически сойтись к устойчивой точке, но по пути уйти в отрицательные C или I. Экономически допустимое возвращение требует сходимости и пребывания в Q на всём пути. В лаборатории движение по умолчанию прекращается на первом пересечении границы.

По умолчанию выбранная траектория останавливается на первом выходе из Q. Пересечение уточняется внутри шага, без искусственного прижатия решения к оси. При математическом продолжении участок после первого выхода показан пунктиром. Возможный последующий возврат в Q не восстанавливает экономический смысл предшествующего пути.

Фоновые траектории и сепаратриса изображают полную математическую систему, включая затенённую область. Сепаратриса вычисляется из малых отклонений вдоль устойчивого собственного вектора седла при интегрировании назад. Возле слияния равновесий точность снижается; в самой вырожденной точке она не строится.

При |I| или |C| свыше 200 расчёт прекращается: это ограничение визуализации, не отметка бесконечности. Путь может уйти за окно раньше; используйте выбор диапазона. При β = 1 численная энергия сохраняется с малой погрешностью.

08 / ЧТО ОЗНАЧАЕТ РЕЗУЛЬТАТ

Три проверки вместо
одного слова «устойчиво»

01

Есть ли равновесие?

Решаем I = αC и I = C + G(I). Проверяем знаки координат. Параметр β не меняет положение точек.

02

Что делают близкие состояния?

Якобиан различает сток и седло. Для центра и нулевых λ нужен дополнительный анализ. β определяет затухание.

03

Допустим ли весь путь?

Проверяем I(t) ≥ 0 и C(t) ≥ 0 до рассматриваемого времени. При нарушении экономическая интерпретация заканчивается.

Что уточнено в исходном разборе

Основные уравнения, формулы равновесий и численный пример верны. Здесь явно разделены β = 1 и β > 1, доказан нелинейный центр, разобраны сами критические точки и исключение G₀ = 0. Вместо общего выражения «нормальное состояние» используются конкретные свойства: существование равновесия, устойчивость и допустимость пути.

Рост G₀ или k меняет конкретные уравнения, а не описывает всю государственную политику. Модель не учитывает цены, занятость, бюджетное ограничение, долг и ожидания. Порог G₀,c — порог этой модели, не нормативный предел государственных расходов.

Проверьте понимание

1. При β = 1 мнимые λ в нелинейной модели уже доказывают центр?

Верно первое. Здесь центр подтверждает сохраняющаяся энергия со строгим локальным минимумом (§6.5).

2. Путь пришёл к положительному стоку, но раньше C стало отрицательным. Это допустимое экономическое возвращение?

Верно второе. Нужна допустимость всего пути, а не только конечной точки.

3. При G₀ = 0 и линейном правиле после kc исчезают все равновесия в Q?

Верно первое. При k = kc даже появляется целый луч равновесий.

09 / МИНИ-СЛОВАРЬ

Мини-словарь

Автономные расходы
Часть планируемых расходов, не зависящая от текущего дохода в выбранной модели.
Мультипликатор
Отношение изменения равновесного дохода к изменению автономных расходов при фиксированных остальных предпосылках.
Нульклина
Множество точек, где одна компонента скорости равна нулю. Не обязательно является траекторией.
Устойчивость по Ляпунову
Достаточно малые начальные отклонения остаются малыми при всех будущих временах.
Асимптотическая устойчивость
Устойчивость плюс возвращение всех достаточно близких состояний к равновесию.
Центр
Изолированное равновесие, окружённое замкнутыми траекториями. Не притягивает окрестность.
Фокус
Равновесие, около которого траектории закручиваются по спирали; устойчивый фокус притягивает.
Седло
Равновесие с притягивающим и отталкивающим направлениями.
Сепаратриса
Особая траектория, разделяющая области качественно разного движения.
Бассейн притяжения
Начальные состояния, сходящиеся к выбранному аттрактору. Экономическую допустимость нужно проверять дополнительно.
Консервативная система
Система с нетривиальной сохраняющейся величиной E; здесь возникает при β = 1.
Гомоклиническая петля
Траектория, приближающаяся к одному и тому же седлу при t → −∞ и t → +∞.
Седло-узловая бифуркация
Локальное рождение или исчезновение седла и узла. Здесь обычный случай требует β > 1.
