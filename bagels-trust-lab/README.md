# Bagels Trust Lab — бейглы и доверие

Интерактивная научно-познавательная история на русском языке по §3.5 книги
А. В. Белянина и В. П. Зинченко «Доверие в экономике и общественной жизни».
Анализ использует методы §§6.1–6.5 и 7.2 Строгаца. Это исследование
репликаторной модели, а не решение отдельного упражнения Строгаца.

## Модель

`p` — доля доверяющих продавцов, `q` — доля честных покупателей.

```text
p' = α p(1 − p)[(a + b)q − b] + μ(1 − 2p)
q' = β q(1 − q)[p + ε(1 − p)]
```

Исходная модель: `a = 1`, `b = 9`, `α = β = 1`, `ε = μ = 0`.
Допустимая область — инвариантный квадрат `[0, 1] × [0, 1]`.
При `ε = μ = 0` порог честности `q* = b/(a+b)`, а сепаратриса
задаётся аналитически:

```text
F(q) = q^b(1 − q)^a,  r = α/β
p_s(q) = 1 − [F(q)/F(q*)]^r,  0 < q < q*
K = (1 − p)/F(q)^r = const
```

Лаборатория включает шесть готовых сценариев, изменение начальных условий,
выигрышей и темпов адаптации, анимацию, сравнение траекторий и экспорт CSV/SVG.
Расширения `ε` и `μ` помечены отдельно: при их включении исходная аналитическая
сепаратриса и классификация областей не применяются. Наблюдения за оплатой
бейглов служат контекстом; модель не калибрована по данным Фельдмана.

## Запуск и проверка

Откройте `index.html` в браузере или используйте общий предпросмотр клуба.
Адрес после публикации: `/Nonlinear_Dynamics/bagels-trust-lab/`.
Все ресурсы сайта локальны; серверная логика, установка зависимостей и
подключение к интернету для лаборатории не требуются.

```sh
node tests/model.test.cjs
```

Также доступно `npm test` из папки проекта. `package.json` задаёт CommonJS
для совместимости автономного ядра и тестов с общим репозиторием.
Тесты проверяют пороги, точные граничные решения, первый интеграл,
инвариантность квадрата, монотонность `q`, уменьшение шага и расширения.
Контрольный порог при `q₀ = 0.8` в исходной модели:
`p_s = 0.3071211677707627`.

## Файлы и материалы

- `index.html`, `styles.css`, `app.js` — содержание и интерфейс.
- `model.js` — независимое математическое ядро и интегратор RK4.
- `tests/model.test.cjs` — математические проверки.
- `paper/report.pdf` — сопроводительный материал на 14 страницах.
- `assets/bagel.svg` — векторная графика сайта.
- `vendor/katex/` — локальный KaTeX 0.16.22 с официальными шрифтами.
  Лицензия MIT сохранена в `vendor/katex/LICENSE`.

При переносе в клуб исходные файлы из `dist/` размещены непосредственно
в папке проекта. Полные книги и статья из соседней локальной папки не
включены в репозиторий; их библиографические описания сохранены на странице.
Ссылка на AEA открывает внешний сайт только при нажатии.
