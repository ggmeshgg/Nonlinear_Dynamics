# Строгац: задачи 5.3.3–5.3.6

Локальный учебный сайт с решениями и интерактивными фазовыми портретами.

## Открытие

Откройте `index.html` двойным щелчком. Сервер и подключение к интернету не нужны.

Все стили и интерактивность находятся в локальных файлах `styles.css` и `app.js`.

## В составе клуба

Автор: Кирилл (`kir-mash`). Работа получена в архиве `strogatz-5.3.3-5.3.6.zip`.

Сайт: https://ggmeshgg.github.io/Nonlinear_Dynamics/strogatz-5.3.3-5.3.6/

Из корня клуба: `npm run build`, `npm run preview`. Сборка копирует проект
как статическую страницу. JavaScript модели сохранён без изменений.
