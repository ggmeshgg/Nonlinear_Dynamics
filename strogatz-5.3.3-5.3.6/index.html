Короткая памятка по 2D‑системам

Для ẋ = Ax достаточно найти след τ, определитель Δ и собственные значения. Здесь все матрицы устроены так, что ответ получается почти сразу.

седло

Δ < 0

Собственные значения разных знаков. Одно направление притягивает, другое отталкивает.

центр

τ = 0, Δ > 0

Чисто мнимые значения. Замкнутые орбиты и незатухающие колебания.

устойчивый узел

λ₁, λ₂ < 0

Все траектории стремятся к началу координат: чувства затухают.

неустойчивый узел

λ₁, λ₂ > 0

Все ненулевые траектории уходят от начала: чувства усиливаются.

Как читать графикиГоризонталь — чувства Ромео R, вертикаль — чувства Джульетты J. Стрелки показывают мгновенное движение, цветные линии — несколько историй с разными начальными условиями. Меняйте параметры: подпись режима и портрет обновятся.
01

5.3.3 · Out of touch with their own feelings

Не в ладу с собственными чувствами

Ṙ = aJĴ = bR

Оба реагируют только на другого. Быстрый трюк — ещё раз продифференцировать:

Ключевой ходR̈ = abRЗнак произведения ab решает всё.
ab > 0λ = ±√ab → седло. При a,b > 0 взаимность разгоняет любовь или ненависть; при a,b < 0 усиливается противоположность чувств.
ab < 0λ = ±i√(−ab) → центр. Роли любви и ненависти циклически меняются; амплитуда не затухает.
ab = 0Вырожденный случай: один партнёр не реагирует, другой меняется линейно или остаётся неподвижным.
Инвариант и геометрия

bR² − aJ² = const. При ab<0 это эллипсы; при ab>0 — гиперболы. Собственные прямые седла: J = ±√(b/a)R.

02

5.3.4 · Fire and water

Огонь и вода

Ṙ = aR + bJĴ = −bR − aJ

След матрицы равен нулю, а её квадрат особенно прост:

Ключевой ходA² = (a² − b²)IПоэтому λ² = a² − b².
|a| > |b|Действительная пара ±√(a²−b²) → седло. Собственные склонности сильнее реакции друг на друга.
|a| < |b|Мнимая пара ±i√(b²−a²) → центр. Противоположные реакции создают бесконечный цикл.
|a| = |b|Вырождение: A²=0. Есть целая прямая равновесий, остальные траектории — параллельные прямые с линейным движением.
Притягиваются ли противоположности?

Иногда они не сходятся к счастливому равновесию, а вечно кружат вокруг безразличия. Центр здесь нейтрален: ни сближения, ни затухания.

03

5.3.5 · Peas in a pod

Два сапога — пара

Ṙ = aR + bJĴ = bR + aJ

Романтические клоны распадаются на две независимые «истории»:

Замена координатu = R + J, u̇ = (a+b)uv = R − J, v̇ = (a−b)v

(1, 1) · вместе
R = J, оба любят или ненавидят одинаково. Темп λ₊ = a+b.

(1, −1) · врозь
R = −J, один любит, другой ненавидит. Темп λ₋ = a−b.

a < −|b|Оба λ отрицательны → устойчивый узел: чувства сходят на нет.
a > |b|Оба λ положительны → неустойчивый узел: любая эмоция разрастается.
|a| < |b|Знаки различны → седло: одно сочетание затухает, другое усиливается.
Что на границах?

При a=±b одно собственное значение равно нулю: соответствующая диагональ целиком состоит из неподвижных точек.

04

5.3.6 · Romeo the robot

Ромео‑робот

Ṙ = 0Ĵ = aR + bJ

Чувство Ромео заморожено: R(t)=R₀. Для Джульетты остаётся одно линейное уравнение.

Явное решениеb ≠ 0: J(t) = (J₀ + aR₀/b)eᵇᵗ − aR₀/bb = 0: J(t) = J₀ + aR₀t
b < 0Джульетта приходит к J* = −aR₀/b. Если R₀>0, она в итоге любит при a>0 и ненавидит при a<0.
b > 0Равновесие неустойчиво. Почти любое отклонение экспоненциально уносит J к любви или ненависти.
b = 0При aR₀≠0 чувства Джульетты меняются линейно; при aR₀=0 — остаются постоянными.
Линия неподвижных точек

При b≠0: aR+bJ=0. При b=0, a≠0: R=0. Если a=b=0, неподвижна вся плоскость.
