# Gone with the Wind Lab — «Унесённые ветром»

Русскоязычный разбор задачи 7.2.19 Строгаца по модели Ретта и Скарлетт
из статьи [Ринальди, Делла Россы и Ланди](https://doi.org/10.1016/j.physa.2013.03.034).
Эпизоды фильма сопоставлены с графиками статьи, а лаборатория позволяет
изменять начальные условия и параметры.

```text
R' = −R + A_S + k S exp(−S)
S' = −S + A_R + k R exp(−R)
```

R и S — условные уровни чувств Ретта и Скарлетт; A_S и A_R — вклады
их привлекательности для партнёра. При k ≥ 0 и неотрицательных вкладах
привлекательности рассматривается первый квадрант. Реакция q exp(−q)
достигает максимума при q = 1. При A_S = 1,2, A_R = 1 и k = 15
есть два устойчивых узла и седло. Лаборатория показывает нульклины,
сепаратрису, фазовые траектории и временные ряды. В сюжетном режиме
параметры меняются по этапам; это интерпретация фильма, а не
измерение чувств или прогноз отношений.

Откройте `index.html` в браузере или воспользуйтесь предпросмотром клуба.
KaTeX и шрифты поставляются локально; лицензия находится в
`vendor/katex/LICENSE`. Установка зависимостей для сайта не нужна.
Модель интегрируется методом Рунге — Кутты четвёртого порядка.
