# Строгац 6.4.11 — политическая поляризация

Подробное решение упражнения 6.4.11 из *Nonlinear Dynamics and Chaos*
и интерактивная лаборатория на русском языке.

## Модель и предположения

Доли правых `x`, левых `y` и центристов `z` удовлетворяют
`x' = rxz`, `y' = ryz`, `z' = −r(x + y)z`, `x + y + z = 1`.
Население постоянно; крайние группы взаимодействуют только с центристами.
Коэффициент `r` — чистый результат противоположно направленных переходов.

После исключения `z` допустимая область — инвариантный треугольник
`x ≥ 0`, `y ≥ 0`, `x + y ≤ 1`. Разобраны случаи `r > 0`, `r < 0`
и вырожденный случай `r = 0`, включая начальные состояния на границе.

Страница показывает нульклины, начало координат и линию равновесий
`x + y = 1`, радиальные траектории, якобиан и точное решение.
Различаются устойчивость отдельной точки и притяжение к множеству.
Методы связаны с §§6.1–6.4 и сохраняющейся пропорцией крайних групп.
Модель описывает учебный механизм убеждения и не является прогнозом выборов.

## Запуск и проверка

Откройте `index.html` в браузере или используйте общий предпросмотр клуба.
Внешних библиотек, шрифтов и сетевых запросов для симуляции нет.
На GitHub Pages проект размещается под `/Nonlinear_Dynamics/strogatz-6.4.11/`.

`app.js` строит фазовый портрет и временные графики по точному решению.
При `r > 0` и начальных долях `(x₀, y₀, z₀) = (0.2, 0.1, 0.7)`
предел равен `(2/3, 1/3, 0)`. При `r < 0` и `z₀ > 0` предел —
`(0, 0, 1)`. При `z₀ = 0` начальное состояние остаётся равновесием.

Полное решение находится на странице; отдельного PDF нет. Кнопка печати
позволяет сохранить страницу в PDF средствами браузера.
