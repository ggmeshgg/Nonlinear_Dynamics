01 / ПОСТАНОВКА · §6.4

Кто с кем разговаривает?

В задаче рассматривается сильно упрощённая модель Васкеса и Реднера. Население постоянно и разделено на три группы. Левые и правые напрямую друг друга не убеждают; обе группы взаимодействуют с центристами.

x(t)Правые
y(t)Левые
z(t)Центристы

Это доли, а не числа людей: например, x = 0,2 означает 20% населения. Точка над переменной обозначает скорость изменения во времени: ẋ = dx/dt.

ẋ = rxzẏ = ryzż = −rxz − ryz

Один контакт — изменение убеждений

r > 0: представитель крайней группы убеждает центриста.
r < 0: центрист убеждает представителя крайней группы.

Величина |r| задаёт темп изменений. Единица времени в условии не уточняется.

Почему в уравнениях стоят произведения xz и yz?

При однородном перемешивании частота встреч правого с центристом пропорциональна произведению их долей xz. Если правых вдвое больше при том же z, таких встреч вдвое больше. Это тот же принцип парных контактов, который Строгац использует для конкуренции видов в §6.4 (с. 172). Здесь r уже включает масштаб интенсивности контактов.

Слагаемое rxz прибавляется к правым и вычитается у центристов. Поэтому изменение принадлежности человека к группе не меняет общую численность населения.

Что требуется в учебнике

  1. Доказать инвариантность множества x + y + z = 1.
  2. Исследовать долгосрочное поведение при положительных и отрицательных r.
  3. Интерпретировать результат в политических терминах.

Смысл условия передан своими словами. Нульклины, якобиан и лаборатория ниже раскрывают решение методами главы 6.

02 / ПУНКТ (a) · §6.1–6.2

Три переменные,
но только две независимые

1

Проверяем сохранение суммы

Складываем скорости изменения всех групп:

d(x + y + z)/dt = rxz + ryz − rxz − ryz = 0.

Нулевая производная означает постоянную сумму. Если x₀ + y₀ + z₀ = 1, то x(t) + y(t) + z(t) = 1 при всех временах существования решения. Это и есть инвариантность плоскости: начав на ней, система на ней остаётся.

2

Проверяем неотрицательность

Сохранения суммы недостаточно: доли не могут быть отрицательными. При x = 0 имеем ẋ = 0; при y = 0 — ẏ = 0; при z = 0 — ż = 0. Каждая координатная плоскость инвариантна.

Правые части — полиномы, поэтому действует теорема единственности из §6.2. Траектория не может пересечь инвариантную границу и перейти в отрицательные доли: в точке пересечения получились бы два разных решения одной начальной задачи.

Та же проверка через формулу
x(t) = x₀ exp(r ∫₀ᵗ z(u) du),
y(t) = y₀ exp(r ∫₀ᵗ z(u) du),
z(t) = z₀ exp(−r ∫₀ᵗ [x(u) + y(u)] du).

Экспонента положительна. Поэтому знак переменной сохраняется, а отсутствующая вначале группа не возникает сама собой. На компактном симплексе решения ограничены и продолжаются на всё t ≥ 0.

3

Переходим на фазовую плоскость

Подставляем z = 1 − x − y. Состояние общества теперь задаётся точкой (x, y):

ẋ = rx(1 − x − y)ẏ = ry(1 − x − y)
D = {(x, y): x ≥ 0, y ≥ 0, x + y ≤ 1}.

Область D — замкнутый треугольник с вершинами (0,0), (1,0), (0,1). В начале координат все центристы; на диагональной стороне центристов нет. Три его стороны инвариантны.

Для читателя из социальных наук

Фазовая плоскость — карта возможных составов общества. Время не является её осью: оно проявляется в движении точки по этой карте.

03 / ГЕОМЕТРИЯ ПОТОКА · §6.1

Где прекращается изменение?

Нульклина — множество, где равна нулю одна из скоростей. Это ещё не обязательно равновесие: другая переменная может продолжать меняться.

Нульклина ẋ = 0

x = 0   или   x + y = 1

На вертикальной стороне x не меняется. Движение по ней, если оно есть, вертикальное.

Нульклина ẏ = 0

y = 0   или   x + y = 1

На горизонтальной стороне y не меняется. Движение по ней, если оно есть, горизонтальное.

Эти выражения предполагают r ≠ 0. Равновесия лежат на пересечении двух нульклин, где одновременно ẋ = ẏ = 0:

E = {(0,0)} ∪ L,   L = {(a, 1 − a): 0 ≤ a ≤ 1}.

Итак, есть одно изолированное равновесие O = (0,0) и целый отрезок равновесий L. Внутри D при r > 0 обе скорости положительны, а при r < 0 — отрицательны. Стрелки направлены соответственно вправо-вверх и влево-вниз.

Отдельный случай r = 0

Все правые части тождественно равны нулю. Весь треугольник состоит из равновесий; обе нульклины совпадают со всей областью D. Общество сохраняет начальный состав.

В этой модели стороны треугольника одновременно являются нульклинами и инвариантными множествами. Вообще нульклина не обязана быть траекторией — различие подчёркивается в упражнении 6.1.7.

05 / ОТ ПОРТРЕТА К ДОКАЗАТЕЛЬСТВУ · §6.1 И ГЛАВА 2

Почему история идёт по прямой?

Одинаковые относительные скорости

При x, y > 0 делим каждую скорость на размер соответствующей группы:

ẋ/x = rz = ẏ/y
⇒ d(ln x − ln y)/dt = 0
⇒ x(t)/y(t) = x₀/y₀.

Сохраняется отношение долей. Разность x − y вообще не постоянна: её производная равна rz(x − y). Поэтому при r > 0 и 0 < z₀ < 1 абсолютный разрыв между двумя ненулевыми, неравными группами растёт, хотя их пропорция не меняется.

Геометрически там, где ẋ ≠ 0, получаем dy/dx = ẏ/ẋ = y/x. Интегрирование даёт ln y = ln x + const, то есть y = Cx. На осях используем инвариантность, не деление на ноль.

Замена переменных, которая объясняет всё

Пусть s = x + y — суммарная доля крайних групп, а p = x/s — доля правых среди них (при s > 0). Тогда

ṡ = ẋ + ẏ = r(x + y)(1 − x − y) = rs(1 − s),
ṗ = (ẋs − xṡ)/s² = 0.

Динамика разделяется на две части: s меняется логистически, p постоянно. Эквивалентно, для центристов ż = −rz(1 − z). Это уже одномерная задача из главы 2, особенно §2.3–2.4.

r > 0

0 ← ← ← 1

Для 0 < z < 1: ż < 0.
Доля центристов убывает к нулю.

r < 0

0 → → → 1

Для 0 < z < 1: ż > 0.
Доля центристов растёт к единице.

Почему предел — именно конец отрезка? Монотонная ограниченная функция z(t) имеет предел. Если бы он лежал строго между 0 и 1, скорость −rz(1 − z) оставалась бы отделённой от нуля, что несовместимо со сходимостью.

Точное решение: ещё одна проверка

При 0 < s₀ < 1 разделяем переменные:

ds/[s(1 − s)] = r dt
⇒ ln[s/(1 − s)] = rt + ln[s₀/(1 − s₀)].

Обозначим s₀ = x₀ + y₀ = 1 − z₀ и Q(t) = s₀ + z₀e−rt. Получаем:

x(t) = x₀/Q(t),   y(t) = y₀/Q(t),
z(t) = z₀e−rt/Q(t).

Q(t) > 0 при любом конечном t. Прямая подстановка подтверждает, что эти формулы верны также при s₀ = 0, s₀ = 1 и r = 0. Сумма долей равна единице. В лаборатории используется именно это решение.

Траектории не пересекаются в начале координат

Лучи геометрически сходятся к O, но разные движущиеся решения не проходят через O за конечное время. Они лишь приближаются к нему при бесконечном времени в соответствующем направлении. Это согласуется с единственностью из §6.2.

06 / ЛОКАЛЬНЫЙ АНАЛИЗ · §6.3–6.4

Устойчивость точки
и устойчивость множества

Равновесие устойчиво, если достаточно малое возмущение остаётся малым. Оно асимптотически устойчиво, если вдобавок все достаточно близкие состояния со временем возвращаются именно к нему. Далее устойчивость рассматривается относительно допустимой области D.

Шаг 1. Якобиан — скорости малых отклонений

Для f = rx(1 − x − y), g = ry(1 − x − y) выписываем частные производные. Например, ∂f/∂x = r[(1 − x − y) − x] = r(1 − 2x − y).

J(x,y) = r 1 − 2x − y−x−y1 − x − 2y

Вблизи равновесия малое отклонение δ = (δx, δy) удовлетворяет приближённому уравнению δ̇ ≈ Jδ. Собственное значение λ описывает множитель eλt вдоль соответствующего направления: отрицательное значение означает затухание, положительное — рост.

Шаг 2. Полностью центристское состояние O

J(0,0) = rI,   λ₁ = λ₂ = r.

При r > 0 точка O — неустойчивый узел (источник). При r < 0 — асимптотически устойчивый узел (сток). При r ≠ 0 равновесие гиперболическое, и §6.3 гарантирует правильность вывода об устойчивости по линеаризации. Радиальная геометрия дополнительно доказана точными лучами.

Шаг 3. Отрезок L: нулевое собственное значение

В произвольной точке q = (a, 1 − a), 0 ≤ a ≤ 1:

J(q) = −r aa1 − a1 − a
det(J − λI) = λ(λ + r) = 0
⇒ λ₁ = 0,   λ₂ = −r.

Вдоль отрезка, в направлении (1, −1), собственное значение равно нулю: рядом лежит другое равновесие. В направлении (a, 1 − a), поперечном отрезку, собственное значение равно −r. Это радиальное направление; оно не обязано быть перпендикулярным L.

Нулевая λ — повод продолжить анализ

Как предупреждает §6.3, линеаризация сама по себе не решает вопрос об устойчивости в вырожденном направлении. Здесь помогают точные координаты (s, p): при s ≈ 1 и r > 0 величина s стремится к 1, а p остаётся прежним.

РежимНачало OОтрезок L
r > 0Неустойчивый узелПритягивает поперёк себя. Каждая точка устойчива, но не асимптотически устойчива.
r < 0Асимптотически устойчивый узелОтталкивает внутрь D. Каждая точка неустойчива относительно D.

Почему точка на L устойчива при r > 0, но не притягивает всю окрестность?

Около q координаты (s,p) непрерывно связаны с (x,y). Начав рядом, получаем p рядом с a, а s(t) остаётся между s₀ и 1. Значит, траектория остаётся рядом с q. Но если p ≠ a, её предел (p,1 − p) отличается от q. Более того, любое соседнее равновесие остаётся неподвижным и никогда к q не приходит. Это исключает асимптотическую устойчивость отдельной точки.

Бассейны притяжения: связь с §6.4

При r < 0 бассейн O равен D ∖ L: все состояния с z₀ > 0 сходятся к центру. При r > 0 отрезок L как множество притягивает D ∖ {O}. В конкретную точку q = (a,1 − a) сходится только её луч {sq: 0 < s ≤ 1}. Этот луч не содержит двумерной окрестности q.

В отличие от примера «кролики и овцы» в §6.4, здесь нет седла и сепаратрисы, разделяющей победу левых и правых. При ненулевых начальных долях обе крайние группы сохраняются в пределе r > 0. Замкнутых непостоянных орбит нет: s строго монотонно при 0 < s < 1 и r ≠ 0.

07 / ПУНКТЫ (b) И (c)

Что модель предсказывает?

r > 0

Центр исчезает.
Пропорция сохраняется.

Если x₀ + y₀ > 0, то

(x∞, y∞, z∞) =
(x₀/(x₀+y₀), y₀/(x₀+y₀), 0).

При x₀, y₀ > 0 остаются обе стороны спектра. Если одной из них изначально нет, сохраняется только другая. При z₀ = 0 начальный состав уже является равновесием.

Исключение: полностью центристское общество (0,0,1) остаётся таким навсегда, хотя это неустойчивое равновесие.

r < 0

Центр растёт.
Крайние группы исчезают.

Если z₀ > 0, то

(x∞, y∞, z∞) = (0,0,1).

Любая положительная начальная доля центристов приводит к полностью центристскому пределу. Отношение x/y при обеих ненулевых группах сохраняется на каждом конечном времени, даже когда обе доли стремятся к нулю.

Исключение: при z₀ = 0 ничего не меняется: центристы не возникают спонтанно.

ПРИМЕР · r > 0
20% / 10% / 70%→66⅔% / 33⅓% / 0%

Порядок: правые / левые / центристы. Начальная пропорция 2 : 1 между крайними группами сохраняется. Это предел при t → ∞.

Социальный смысл и пределы интерпретации

Модель описывает усиление крайних групп при r > 0 и движение к центру при r < 0. «Поляризация» здесь означает исчезновение центристов; двухстороннее разделение возникает только при наличии обеих крайних групп вначале. Если одна сторона отсутствует, получается согласие на одном краю спектра.

Нет механизма прямого перехода между левыми и правыми, спонтанной смены взглядов, различий в убедительности двух сторон или структуры социальной сети. Поэтому постоянство пропорции — следствие симметрии уравнений. Это учебная модель взаимодействий, а не прогноз выборов или универсальный закон политического поведения.

Метод, который можно перенести в следующую задачу

Смысл переменных → допустимая область → инвариантность → нульклины и равновесия → знаки скоростей → линеаризация → глобальная геометрия → содержательная интерпретация. Если есть сохраняющаяся величина, проверьте, помогает ли она уменьшить размерность.

08 / ПРОВЕРКА ПОНИМАНИЯ

Три коротких вопроса

01. При r < 0 и z₀ = 0 что произойдёт?

Верно второе: при z = 0 все три скорости равны нулю. Направление убеждения не помогает группе, которой изначально нет.

02. При r > 0 каждая точка на L асимптотически устойчива?

Верно первое. Притяжение к множеству и возвращение в конкретную точку — разные свойства.

03. Если x₀ : y₀ = 3 : 1, какая пропорция будет позже?

Верно второе. Обе доли умножаются на один и тот же множитель 1/Q(t). Для этих начальных условий x₀, y₀ положительны.
