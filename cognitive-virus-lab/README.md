# Cognitive Virus Lab — когнитивная автономность

Интерактивная лаборатория на русском языке по теоретической модели
Solé и соавторов, *Large-Language Models as a Cognitive Virus*,
arXiv:2609.03344v1 (2026). Математический разбор использует фазовые
портреты и устойчивость, знакомые по главе 6 Строгаца. Это исследование
модели из препринта, а не решение отдельного упражнения Строгаца.

## Модель и предположения

Доли автономных людей `U`, взаимодействующих с ИИ `C` и зависимых `D`
неотрицательны и удовлетворяют `U + C + D = 1`. Обозначим
`f(U) = ρ − λU + κU²`. После исключения `D`:

```text
U' = C f(U)
C' = σ(1 − U) − C[f(U) + μ + σ]
D = 1 − U − C
```

`λ` задаёт распространение взаимодействия с ИИ, `ρ` — возвращение к
автономности, `κ` — коллективную поддержку автономности, `μ` — переход
от взаимодействия к зависимости, `σ` — восстановление из зависимости.
Модель усредняет индивидуальные различия и структуру контактов.
Параметры и веса показателя навыка иллюстративны, не оценены по данным.

Лаборатория включает пять экспериментов, выбор начального состояния в
инвариантном треугольнике, сравнение двух обществ, анимацию, нульклины,
равновесия, пороги и численный проход по петле гистерезиса.
Она не диагностирует зависимость отдельного человека и не оценивает
эффективность вмешательств.

## Запуск и проверка

Откройте `index.html` в браузере или используйте общий предпросмотр клуба.
Адрес после публикации: `/Nonlinear_Dynamics/cognitive-virus-lab/`.
Ресурсы и формулы локальны; установка зависимостей и интернет для
лаборатории не требуются. Ссылка на препринт открывается по нажатию.

```sh
node tests/model.test.cjs
```

Также доступно `npm test` из папки проекта. Локальный `package.json`
задаёт CommonJS для математического ядра и тестов внутри общего
репозитория с типом ES modules.

Тесты проверяют равновесия, бассейны, инвариантную сепаратрису,
сохранение суммы долей, граничные состояния, крайние скорости,
восстановление, численную петлю и корректность формул KaTeX.
При `λ = 0.45`, `ρ = 0.1`, `κ = 0.4`, `μ = 0.2`, `σ = 0.1`
пороги равны `λ_SN = 0.4`, `λ_c = 0.5`; корни по `U` равны
приблизительно `0.304806` и `0.820194`.

Траектории вычисляются RK4 с шагом не более 0.2 условной единицы;
равновесия и пороги — аналитически. Последний кадр конечной траектории
не обязательно совпадает с пределом. Для демонстрации вторжения при
проходе по петле явно добавляется малое ненулевое использование ИИ.

## Файлы и лицензия

- `index.html`, `style.css`, `app.js` — содержание и интерфейс.
- `model.js` — независимое ядро расчётов.
- `tests/model.test.cjs` — математические проверки.
- `icon.svg` — значок сайта.
- `vendor/katex/` — локальные KaTeX и шрифты; лицензия MIT
  сохранена в `vendor/katex/LICENSE`.
