Inside the model

Only two states

ḣ = sat(u_c, 0, u_max) − c(t)√h
ż = the selected memory rule

The tank has normalized unit area. The water level stays nonnegative. There is no pump lag, thermal state, pressure compensation, or overflow model. The drawing scales to the run; its rim is not a capacity limit.

Two parallel outlets

Branch 1 always drains c₀√h. While branch 2 is open, it adds (c₁ − c₀)√h. Total flow is c₁√h. After it closes, total flow is c₀√h again.

We control the level, so the original branch returns to its original drip rate when h returns to h★.

Read the phase portrait

The vertical target line is where ż changes sign for ordinary integral control. Above z = u_max / K_I, the integral controller requests more than the pump can deliver.

The field switches when the second branch opens or closes. The state does not jump. Constant and proportional control leave z fixed; their memory coordinate is inactive.
