# Локальная карта PI-регулятора

Восьмистраничный учебный разбор на русском. Документ относится к заданной модели бака; графики фазовых портретов и временных рядов построены для её линейного приближения. Карта рассматривает только KI > 0. Нелинейная бифуркация Хопфа не объявляется доказанной.

## Сборка

Готовые изображения включены, поэтому для сборки PDF достаточно Typst и шрифта Noto Sans:

```sh
typst compile local-regime-map.typ local-regime-map.pdf
```

Проверено с Typst 0.15.0. Все пути к изображениям относительные, внешние Typst-пакеты не используются.

## Пересоздание графиков

Необходимы Python, NumPy, SciPy, Matplotlib и шрифт DejaVu Sans:

```sh
python3 plots.py
typst compile local-regime-map.typ local-regime-map.pdf
```

Граница устойчивости: KP = -0.3. Граница узла и спирали: KI = (KP + 0.3)^2 / 4. Собственные значения контрольных точек печатаются при запуске plots.py. Портреты и временные ряды вычисляются матричной экспонентой, без пошагового интегрирования.
