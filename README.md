# Интерактивная лекция: последовательный RLC-контур

Образовательный сайт на русском языке: от закона Кирхгофа к вынужденным колебаниям, резонансу, фазовой плоскости и устойчивости. 10 разделов, SVG-схема, синхронные ползунки и числовые поля, начальные условия, три графика Plotly, интерактивная диаграмма след–детерминант и режим лекции (←, →, Esc).

**GitHub Pages:** https://norff21-hash.github.io/rlc-interactive-lecture/

## Модель

`L q'' + R q' + q/C = Um cos(2πft)`, `I=q'`, `Uc=q/C`.

Внутри ядра — SI. `β=R/(2L)`, `ω₀=1/√(LC)`, `Rcrit=2√(L/C)`, `Q=√(L/C)/R`. Учитываются произвольные начальные условия, критическое затухание, постоянный источник и идеальный резонанс. L=0 и C=0 выводят пояснение и отключают некорректные графики. При R=0 бесконечная добротность показывается символически, бесконечная установившаяся амплитуда — разрывом.

Классификация при гармоническом источнике относится к однородной системе отклонений, а не к постоянной точке неавтономной системы.

## Стек и структура

React, TypeScript, Vite, KaTeX, Plotly.js/react-plotly.js, SVG, Vitest. Backend не требуется.

```
src/math/              чистое математическое ядро, SI и sampling
src/components/        поля, формулы, метрики, навигация
src/visualizations/    схема, три графика и диаграмма τ–Δ
src/theory/            авторский текст лекции
src/data/              лабораторные и демонстрационные пресеты
src/tests/             физические формулы и граничные случаи
docs/source-notes.md   сверка формул с материалами
scripts/               браузерная проверка
.github/workflows/     тестирование и публикация
```

## Запуск и проверка

Требуется Node.js 22+ и npm.

```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

Браузерная проверка production-сборки:

```bash
npx playwright install chromium
npm run test:browser
```

Проверяются формулы, ODE по закону Кирхгофа, все режимы, начальные условия, сохранение энергии идеального LC, резонанс, вырожденные параметры и сетка крайних значений. Браузерная проверка охватывает графики, KaTeX, поля, пресеты, режим лекции и мобильную ширину. Скриншоты сохраняются в `test-results/`.

## GitHub Pages

Workflow при push в main устанавливает зависимости, запускает unit-тесты, сборку и браузерную проверку, затем публикует dist. Vite base: `/rlc-interactive-lecture/`.

В Settings → Pages выбрать Source: GitHub Actions. Workflow также запрашивает автоматическое включение Pages через configure-pages. Если организация или токен не разрешают включение, настройку выполняет владелец репозитория. Проверить результат можно во вкладке Actions.
